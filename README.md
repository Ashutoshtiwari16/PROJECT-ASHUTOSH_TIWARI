# AI Expense Tracker

A simple Python application that helps you track daily expenses, understand your spending habits, and manage your money better.

## About the Project

I built this project to make expense tracking easier and help people understand where their money goes. It uses Python, Streamlit, and SQLite to manage expenses and provide spending insights.

## Features

- Add and manage daily expenses.
- Organize expenses into different categories.
- Analyze spending habits.
- Get rule-based spending insights.
- Store expense records using SQLite.
- Use a simple Streamlit interface.

## Real-Life Example

Imagine a college student who receives ₹5,000 per month but often loses track of spending on food, travel, and shopping.

Using this application, they can record their expenses, identify where most of their money goes, and understand where they can cut back.

## Tech Stack

- Python
- Streamlit
- SQLite
- Data Analysis

## How to Run

Clone the repository:

```bash
git clone https://github.com/Ashutoshtiwari16/PROJECT-ASHUTOSH_TIWARI.git
cd PROJECT-ASHUTOSH_TIWARI/AI-EXPENSETRACKER
```

Create and activate a virtual environment on Windows:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Install dependencies and start the application:

```bash
pip install -r requirements.txt
streamlit run app/main.py
```
